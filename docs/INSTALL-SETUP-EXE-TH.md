# ติดตั้ง HR Auto จากไฟล์ Setup.exe

[ศูนย์รวมเอกสาร](README.md) · [คู่มือใช้งาน](USER-GUIDE-TH.md) · [แก้ปัญหา](TROUBLESHOOTING-TH.md)

คู่มือนี้สำหรับคนที่ได้รับไฟล์ `HR-Auto-Setup-x.x.x.exe` มาติดตั้ง ไม่ต้องลง Node.js ไม่ต้องใช้ Git และไม่ต้องพิมพ์คำสั่งใดๆ ทั้งสิ้น เพราะทุกอย่างถูกแพ็กมาในไฟล์เดียวแล้ว

> ถ้าคุณเป็นคนสร้างไฟล์ Setup.exe เอง ดูวิธีสร้างที่ [BUILD-INSTALLER-TH.md](BUILD-INSTALLER-TH.md)

## สิ่งที่ต้องมี

- Windows 64-bit
- พื้นที่ว่างในไดรฟ์ C ประมาณ 1 GB
- **ไม่ต้อง**ใช้สิทธิ์ Administrator

## ขั้นตอนติดตั้ง

1. ดับเบิลคลิกไฟล์ `HR-Auto-Setup-x.x.x.exe`

2. **ถ้า Windows ขึ้นหน้าจอสีน้ำเงินว่า "Windows protected your PC"** ให้กด `More info` แล้วกด `Run anyway`

   หน้าจอนี้ขึ้นเพราะไฟล์ยังไม่ได้ซื้อใบรับรองดิจิทัล (Code Signing Certificate) ไม่ได้แปลว่าไฟล์มีไวรัส ถ้าไม่มั่นใจให้ถามคนที่ส่งไฟล์ให้ยืนยันก่อน

3. กด `ถัดไป` ไปเรื่อยๆ จนกด `ติดตั้ง` แล้วรอสักครู่ (ไฟล์ใหญ่ ใช้เวลา 1-2 นาที)

4. ติ๊ก `เปิด HR Auto` แล้วกด `เสร็จสิ้น`

โปรแกรมจะถูกติดตั้งที่ `C:\Users\<ชื่อคุณ>\AppData\Local\Programs\HR Auto`

## เปิดโปรแกรมยังไง

เปิดได้ 3 ทาง เลือกทางไหนก็ได้:

- **ไอคอน `HR Auto` บนหน้าจอ Desktop** (ตัวติดตั้งสร้างให้อัตโนมัติ)
- **Start Menu** → พิมพ์ `HR Auto`
- เข้าไปในโฟลเดอร์ที่ติดตั้ง แล้วดับเบิลคลิกไฟล์ **`HR Auto.cmd`**

> **ระวังสับสน:** ถ้าตอนติดตั้งคุณเปลี่ยนโฟลเดอร์ปลายทางไปไว้บน Desktop จะเห็น *โฟลเดอร์สีเหลือง* ชื่อ HR Auto ด้วย โฟลเดอร์นั้นคือตัวโปรแกรม **ไม่ใช่ปุ่มเปิด** ให้กดที่ไอคอนทางลัดหรือไฟล์ `HR Auto.cmd` แทน

## เปิดใช้งานครั้งแรก

เมื่อเปิดโปรแกรม จะมี **2 หน้าต่างขึ้นมา**

| หน้าต่าง | หน้าที่ | ปิดได้ไหม |
|---|---|---|
| หน้าต่างดำ (Console) | ตัวโปรแกรมที่กำลังทำงาน | **ห้ามปิด** ปิดเมื่อไหร่โปรแกรมหยุดทันที |
| หน้าเว็บ HR Auto | หน้าจอที่คุณใช้งาน | ปิดได้ เปิดใหม่ที่ <http://127.0.0.1:4173> |

ถ้าหน้าเว็บไม่เปิดเอง ให้เปิดเบราว์เซอร์แล้วพิมพ์ <http://127.0.0.1:4173>

### ล็อกอิน Facebook ของคุณเอง

ครั้งแรกที่สั่งงานที่ต้องใช้ Facebook ระบบจะเปิดหน้าต่าง Chrome ขึ้นมาให้ล็อกอิน **ให้ล็อกอินด้วยบัญชี Facebook ของคุณเอง** ระบบจะจำ Session ไว้ในเครื่องคุณ ไม่ต้องล็อกอินซ้ำทุกครั้ง

ไฟล์ติดตั้งนี้**ไม่มี**บัญชี Facebook หรือ Session ของคนอื่นติดมาด้วย

## ข้อมูลของคุณเก็บที่ไหน

```text
C:\Users\<ชื่อคุณ>\AppData\Local\HR-Auto\data\
├── hr-auto.sqlite       ฐานข้อมูล Draft กลุ่ม และคิว
├── uploads/             รูปที่แนบใน Draft
├── evidence/            ภาพหลักฐานการโพสต์
└── browser-profile/     Session Facebook ของคุณ
```

เปิดเร็วๆ ได้โดยกด `Win + R` แล้ววาง `%LOCALAPPDATA%\HR-Auto\data`

**โฟลเดอร์นี้ห้ามส่งให้ใคร** เพราะใน `browser-profile/` มี Session Facebook ของคุณ ใครได้ไปคือเข้าบัญชีคุณได้

## วิธีปิดโปรแกรม

ปิดหน้าต่างดำ (Console) หรือกด `Ctrl + C` ในหน้าต่างนั้น การปิดแค่หน้าเว็บไม่ได้ทำให้โปรแกรมหยุด

## ถอนการติดตั้ง

ไปที่ `Settings` → `Apps` → `Installed apps` → หา `HR Auto` → `Uninstall`

**ข้อมูลใน `%LOCALAPPDATA%\HR-Auto` จะไม่ถูกลบ** เพื่อกันข้อมูลหายโดยไม่ตั้งใจ ถ้าต้องการลบจริงๆ ให้ลบโฟลเดอร์นั้นเองหลังถอนการติดตั้ง (สำรองไว้ก่อนเสมอ)

## ปัญหาที่พบบ่อย

**Antivirus แจ้งเตือนหรือลบไฟล์ทิ้ง**
โปรแกรมประเภทควบคุมเบราว์เซอร์อัตโนมัติมักถูกแจ้งเตือนผิดพลาด ให้เพิ่มโฟลเดอร์ติดตั้งเข้า Exclusion หรือสอบถามคนที่ส่งไฟล์ให้

**เปิดแล้วหน้าต่างดำเด้งหายทันที**
มักเกิดจากมีโปรแกรมอื่นใช้พอร์ต 4173 อยู่ หรือ HR Auto เปิดค้างอยู่แล้ว ให้เปิด <http://127.0.0.1:4173> ดูก่อน ถ้ายังไม่ได้ให้รีสตาร์ทเครื่องแล้วลองใหม่

**ขึ้นข้อความว่า "พบ HR Auto คนละชุดกำลังทำงานอยู่"**
แปลว่ามี HR Auto อีกชุดหนึ่งเปิดค้างอยู่บนพอร์ตเดียวกัน แต่ใช้ข้อมูลคนละที่กัน ระบบจะไม่เปิดทับให้เพื่อกันข้อมูลปนกัน ให้ปิดหน้าต่าง HR Auto เดิมให้หมดก่อน แล้วกดเปิดใหม่

**ขึ้นว่า "ไม่ตอบสนองภายใน 20 วินาที"**
เครื่องช้าหรือ Antivirus กำลังสแกนอยู่ ให้ปิดหน้าต่างแล้วเปิดใหม่อีกครั้ง

**อยากเปลี่ยนพอร์ต**
ยังทำจากหน้าโปรแกรมไม่ได้ ต้องให้คนดูแลระบบตั้งค่าให้ ดู [CONFIGURATION-TH.md](CONFIGURATION-TH.md)

ปัญหาอื่นๆ ดูที่ [TROUBLESHOOTING-TH.md](TROUBLESHOOTING-TH.md)

## ข้อควรระวังในการใช้งาน

- ใช้กับบัญชีและกลุ่ม Facebook ที่คุณมีสิทธิ์เข้าถึงเท่านั้น
- ตรวจข้อความ รูป และรายชื่อกลุ่มทุกครั้งก่อนยืนยัน
- ถ้าเจอ CAPTCHA, Checkpoint หรือข้อความจำกัดบัญชี ให้หยุดใช้งานทันทีและแจ้งคนดูแล ระบบจะพักคิวให้อัตโนมัติเมื่อตรวจพบ
- อย่าตั้งจำนวนแท็บสูงเกินกำลังเครื่อง และอย่าลดเวลาหน่วงระหว่างโพสต์
