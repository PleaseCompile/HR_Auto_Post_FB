## เลือก Workflow

### Dry run

ใช้เมื่อ:

- กลุ่มใหม่
- ไม่แน่ใจสิทธิ์
- Facebook UI เปลี่ยน
- เพิ่ง Login ใหม่

### Assisted ทีละกลุ่ม

ใช้เมื่อ:

- ข้อความสำคัญ
- กลุ่มมีกฎเฉพาะ
- เครื่องมี RAM จำกัด
- ต้องตรวจละเอียด

### หลายหน้าต่าง — ค่าแนะนำสำหรับคิวจำนวนมาก

ใช้เมื่อ:

- กลุ่มจำนวนมาก
- ผู้ใช้ต้องการแบ่งงานหน้าต่างละไม่เกิน 30 แท็บ
- ผู้ใช้จะกด Post และปิดแท็บเอง
- เครื่องมี RAM เพียงพอ

ตรวจข้อความสรุปก่อนเริ่ม เช่น 80 กลุ่มต้องแสดง `30 + 30 + 20` และต้องเข้าใจว่า `หยุดคิว` จะไม่ปิดแท็บ

### Hybrid แนะนำ

ใช้เป็นค่าเริ่มต้นเมื่อผู้ใช้ต้องการให้ HR Auto ปิดแท็บที่บันทึกผลแล้วและหมุนเวียนรายการถัดไปตามเพดานพร้อมกัน เริ่มที่ 10 แท็บ แม้เครื่องมี RAM 32 GB

## ระหว่างรัน

- [ ] อย่าปิด Chromium หลัก
- [ ] โหมดหลายหน้าต่าง: อย่าปิดแท็บก่อนบันทึกผลใน HR Auto
- [ ] ตรวจว่าแต่ละหน้าต่างมีไม่เกิน 30 แท็บ
- [ ] ตรวจชื่อกลุ่มในทุก Dialog
- [ ] ตรวจข้อความและรูป
- [ ] กด `ยืนยันและโพสต์` เฉพาะเมื่อพร้อม
- [ ] ถ้ากด Post เอง ให้เลือก `ฉันโพสต์เองแล้ว`
- [ ] ถ้าข้าม ให้ใส่เหตุผลและเก็บหลักฐาน
- [ ] ถ้า CAPTCHA/Checkpoint ให้หยุดทั้งคิว
- [ ] ไม่กดเริ่มคิวซ้ำ
- [ ] หากระบบพักการเติมแท็บเพราะ RAM ต่ำ ให้จัดการแท็บที่เปิดอยู่ก่อน ไม่ต้องกดเริ่มคิวซ้ำ
- [ ] หากสถานะ Settings แสดง Renderer crash ให้หยุดเพิ่มแท็บและตรวจ `data/browser-events.jsonl`

## ก่อนปิดระบบ

- [ ] ไม่มี Target อยู่ `submitting`
- [ ] ตัดสินใจ Target ที่ `awaiting_confirmation`
- [ ] พัก/หยุดคิวอย่างถูกต้อง
- [ ] ปิดแท็บและหน้าต่างของโหมดหลายหน้าต่างด้วยตนเองเมื่อบันทึกผลครบ
- [ ] ปิด Facebook Session จาก Settings
- [ ] กด `Ctrl+C`
- [ ] ตรวจ Backup ตามรอบ

## สรุปรายวัน

ตั้งตัวกรอง:

- ช่วงด่วน: วันนี้
- ยึดวันที่จาก: วันที่งานของรอบ
- ช่วงโพสต์: เช้า/กลางวัน/เย็น
- มุมมอง: จัดกลุ่มตามรอบคิว
- เรียง: ล่าสุดก่อน

ตรวจ:

- จำนวนเผยแพร่แล้ว
- จำนวนรออนุมัติ
- จำนวนต้องตรวจ
- จำนวนไม่สำเร็จ
- รายการข้าม
- หลักฐานที่ขาด

## ส่งมอบกะหรือส่งต่อผู้ใช้

ระบุ:

```text
วันที่/รอบ:
Run ID:
บัญชี Facebook:
เผยแพร่:
รออนุมัติ:
ต้องตรวจ:
ไม่สำเร็จ:
คิวที่ยังรอ:
ปัญหาที่พบ:
สิ่งที่ห้ามทำซ้ำ:
```

ห้ามส่ง Browser Profile หรือ Cookie เพื่อส่งมอบกะ ให้ผู้รับใช้บัญชีที่ได้รับอนุญาตและ Login ด้วยตนเอง
