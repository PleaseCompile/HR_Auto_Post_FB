# คู่มืออัปเดต HR Auto (Update Guide)

> **สรุปสั้น:** การอัปเดตนี้เพิ่มโหมด **โพสต์อัตโนมัติ (Auto-Confirm)** ที่มีระบบหน่วงเวลาและ Circuit Breaker ป้องกันโดนบล็อก, เพิ่ม **Custom Tab Limit** ปลดล็อกเพดาน 30 แท็บในโหมด Hybrid Tabs (ตั้งได้สูงสุด 250 แท็บ), และเพิ่ม **Safety Net** ตรวจจับหน้า CAPTCHA/Checkpoint ในขั้นตอนโพสต์แล้วหยุดพักคิวให้อัตโนมัติ

---

## 1. เช็กลิสต์ก่อนอัปเดต (Pre-Update Checklist)

1. **สำรองโฟลเดอร์ `data/`**
   - คัดลอกโฟลเดอร์ `data/` เก็บไว้ที่อื่นชั่วคราว (เช่น `data_backup_2026-08-06`)
   - เพื่อความปลอดภัยของฐานข้อมูล `hr-auto.sqlite` และ Facebook Profile Session (`browser-profile`)
2. **ปิดโปรแกรมและ Browser ที่รันอยู่**
   - ปิดแท็บเว็บ HR Auto ในเบราว์เซอร์
   - ปิด Chromium ที่ HR Auto เปิดค้างไว้
   - หากรันผ่าน PowerShell / Terminal ให้กด `Ctrl + C` เพื่อหยุดโปรแกรมก่อนอัปเดต

---

## 2. ขั้นตอนอัปเดต (Step-by-Step Update)

คัดลอกและรันคำสั่งตามลำดับใน PowerShell (Windows) หรือ Terminal (Linux):

### สำหรับ Windows (PowerShell)

```powershell
# 1. ดึงโค้ดล่าสุดจาก GitHub
git pull origin main

# 2. ติดตั้งแพ็กเกจที่จำเป็น
npm install

# 3. คอมไพล์ TypeScript เป็น JavaScript
npm run build

# 4. เริ่มโปรแกรมใหม่
powershell -ExecutionPolicy Bypass -File .\scripts\start-windows.ps1
```

### สำหรับ Linux Desktop (Terminal)

```bash
# 1. ดึงโค้ดล่าสุดจาก GitHub
git pull origin main

# 2. ติดตั้งแพ็กเกจที่จำเป็น
npm install

# 3. คอมไพล์ TypeScript เป็น JavaScript
npm run build

# 4. เริ่มโปรแกรมใหม่
./scripts/start-linux.sh
```

## 3. สิ่งที่เปลี่ยนและจุดสังเกตก่อนใช้งาน (What's Changed)

### 1. โหมดโพสต์อัตโนมัติ (Auto-Confirm Toggle)
- ในหน้า **คลังกลุ่ม** บริเวณแถบสร้างคิวโพสต์ มีตัวเลือกใหม่: `[ ] โหมดโพสต์อัตโนมัติ (Auto-confirm)`
- หากติ๊กเปิด: เมื่อกด "สร้างคิวโพสต์" ระบบจะมีกล่องแจ้งยืนยันการตรวจสอบข้อความ รูปภาพ และรายชื่อกลุ่ม 1 ครั้ง
- เมื่อเริ่มรัน ระบบจะหน่วงเวลาสุ่ม (5–15 วินาที) แล้วกด Post ใน Facebook ให้เองทีละกลุ่มโดยไม่ต้องกด "ยืนยันและโพสต์" เองทีละกลุ่ม
- แสดงป้าย **AUTO-CONFIRM** สีฟ้าบนการ์ดคิวงาน โดยยังคงปุ่ม "ข้าม", "พัก", "หยุด" ไว้เป็นทางออกฉุกเฉินตลอดเวลา

### 2. ปรับจำนวนแท็บพร้อมกันใน Hybrid Tabs (Custom Tab Limit)
- ในหน้า **คลังกลุ่ม** ช่องเลือกจำนวนแท็บ `runTabLimit` สำหรับโหมด Hybrid Tabs เพิ่มตัวเลือก `50 แท็บ`, `100 แท็บ` และ `กำหนดเอง…` (ระบุตัวเลขได้ตั้งแต่ 1-250)
- โหมด Hybrid Windows ยังคงเพดานสูงสุด 30 แท็บต่อหน้าต่างตามเดิมเพื่อความปลอดภัยในการตรวจด้วยมือ

### 3. ระบบความปลอดภัยอัตโนมัติ (Safety Net Guard)
- เมื่อระบบพบหน้ายืนยันตัวตน, CAPTCHA, ล็อกอิน หรือคำเตือนบัญชีถูกจำกัด ระบบจะหยุดพักคิว (`paused`) อัตโนมัติทันที ไม่พยายามคลิกต่อ
- มี Circuit Breaker หยุดพักคิวอัตโนมัติหากพบโพสต์ล้มเหลวติดต่อกัน 2 ครั้ง

## 4. ผลกระทบต่อคิวเดิมที่ค้างอยู่ (Existing Queues & Database)

- **ฐานข้อมูล (SQLite):** ระบบมี Migration อัตโนมัติ (`ALTER TABLE runs ADD COLUMN auto_confirm INTEGER DEFAULT 0`) เมื่อเปิดโปรแกรมใหม่ ฐานข้อมูลเดิมและคิวเดิมจะใช้งานได้ตามปกติโดยไม่ต้องรันคำสั่ง DB เพิ่มเติม
- **คิวเดิมที่ค้างอยู่:** คิวเดิมที่สร้างก่อนการอัปเดตจะมีค่า `autoConfirm = false` (รอยืนยันตามพฤติกรรมเดิม) จึงไม่มีความเสี่ยงเรื่องคิวเดิมถูกโพสต์เองโดยไม่ได้ตั้งใจ
- **คำแนะนำ:** หากมีคิวที่ทำงานค้างอยู่ก่อนปิดโปรแกรม แนะนำให้หยุดคิวและปิดแท็บ Browser ให้เรียบร้อยก่อนกดอัปเดต

## 5. การแก้ปัญหาเบื้องต้นและการย้อนกลับ (Troubleshooting & Rollback)

### หากอัปเดตแล้วเปิดไม่ได้ หรือเจอข้อผิดพลาด

1. ตรวจสอบว่าได้รัน `npm run build` หรือยัง
2. ตรวจสอบว่าไม่มี Node.js หรือ Chromium ค้างอยู่ (`EADDRINUSE` พอร์ต 4173)
3. รัน `npm run check` เพื่อตรวจสถานะ TypeScript

### วิธีย้อนกลับไปเวอร์ชันเดิม (Rollback)

หากพบปัญหาและต้องการย้อนกลับไป commit ก่อนหน้า:

```bash
# ย้อนกลับไปยัง commit ก่อนหน้า
git reset --hard HEAD~1

# คอมไพล์และเริ่มโปรแกรมใหม่
npm run build
powershell -ExecutionPolicy Bypass -File .\scripts\start-windows.ps1
```
